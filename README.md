# Design without guessing

[Read the illustrated handbook](https://maxiplux.github.io/maxiplux-skills-handbook/)

A practical guide to UI/UX, AI agents, and software architecture. Includes interactive examples, illustrations, and copyable prompts.

[Download the offline HTML](./desing/guide-lines.html). Its reading content, images, styles, and interactions are embedded.

This repository hosts the generated handbook and its linked illustration assets. [Authoring sources](https://github.com/maxiplux/maxiplux-skills) require repository access.

GitHub Pages publishes the root of the main branch. To update, build with `npm run build:public` in the source renderer, copy the contents of `_public-site/` here, then commit and push.
